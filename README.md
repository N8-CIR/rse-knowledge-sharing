# rse-knowledge-sharing

A hub for sharing knowledge and outputs from N8CIR RSE events

This book is published to [RSE Knowledge Sharing](https://n8-cir.github.io/rse-knowledge-sharing/)

## Contributions

Contributions are welcome to this repository. Please feel free to submit pull
requests or raise issues to share your knowledge and outputs from N8CIR RSE events.

## Deployment

To deploy this book, you can use GitHub Pages. The book is automatically published to [RSE Knowledge Sharing](https://n8-cir.github.io/rse-knowledge-sharing/) whenever changes are pushed to the main branch.
